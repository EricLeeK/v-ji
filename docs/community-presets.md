# 社区考试预设卡组

两套卡册分别上架“综合”分类，可搜索标题后免费加入。内容依据用户提供的资料整理；来源页码按 PDF 物理页码记录。原题答案没有声称逐题完成外部权威核验。

## 卡型设计

- 单选：使用选择题卡，保留原题选项。
- 判断：使用“正确 / 错误”双选项；有可靠解析时附纠错点。
- 多选：使用问答卡，先回忆完整选项集合，再翻面核对；当前应用的选择题模板是单选。
- 精确数字、术语、对应关系：使用短挖空，单张笔记至多三个独立空，每个答案不超过18字符。
- 大题：框架卡、分项回忆与整题复述配合；长文件名使用问答，避免手机端出现过长空格。
- 笔记卡：承载学习方法、资料版本和易混关系。

```bash
node scripts/build-community-presets.mjs
node scripts/build-community-presets.mjs --check
npm test -- lib/community-presets.test.ts
```
